# Muhammad Ihsan - IT Portfolio

A modern, responsive resume website showcasing my skills and experience in IT.

## Features

- Clean, dark theme design
- Responsive layout
- Interactive elements
- Professional typography using Poppins font

## Files

- `Resume.html` - Main resume page
- `Resume` - Alternative resume version

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)

## Getting Started

Simply open `Resume.html` in your web browser to view the resume.

## Development

This project uses vanilla HTML and CSS. No build process required.
